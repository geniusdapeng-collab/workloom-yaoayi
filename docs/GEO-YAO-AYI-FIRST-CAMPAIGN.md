# 姚阿姨系统首批 GEO 图文宣传方案

## 目标

用姚阿姨第一人称，以图文为主，把“沂蒙山的人、山里的日子、具体物产的来处”讲成一组能被读者理解、搜索和被 AI 正确引用的内容。首批不以产量、库存、价格或成交承诺为中心，而先建立三个稳定实体：

- 姚阿姨：临沂人、沂蒙女儿，55 岁学咖啡、61 岁回乡，旗袍外面系围裙。
- 沂蒙山咖啡小院：咖啡角与鏊子区在同一个小院里，用来过日子、待客和连接乡亲。
- 沂蒙山风物：先讲来处、时令、吃法和事实边界，再谈是否有货、价格、物流和售后。

## 读者

| 读者 | 想解决的问题 | 本批内容给出的东西 |
| --- | --- | --- |
| 第一次认识姚阿姨的人 | 她是谁，为什么咖啡和煎饼会在同一张桌上 | 稳定身份、杭州学习经历、回乡动机和真实生活场景 |
| 想了解沂蒙山的人 | 这里四季有什么，人怎样过日子 | 小院日记、邻里来往、季节素材和具体动作 |
| 搜索山货的人 | 某样特产是什么、哪里来、怎么吃 | 五栏笔记和逐项待核实的单品说明 |
| 内容与地方品牌同行 | 怎样不靠卖惨、猎奇和虚构把乡村讲清楚 | 事实卡、授权、AI 标识和真实回执方法 |

## 内容主线

1. **小院日记**：从擦杯、烧水、摊煎饼、摆桌、收工等真实动作进入。
2. **笔记翻翻**：用手写卡片讲名字、谁家的或哪里来、味道、吃法、第几号笔记。
3. **山里的客人**：真实到访、真实反应和互相尊重；没有真实素材就不编对白。
4. **手工吃食**：煎饼、豆沫、晒柿饼等工序，以及向谁学、做给谁吃、怎样调整。

每件物产优先建立七类选题：

1. 我在小院里怎么讲这件物产；
2. 先问谁家的、哪里来；
3. 客人真实提问后的回答；
4. 一张五栏手写卡片；
5. 真实时令、处理和吃法；
6. 与物产有关的人不是产品照片里的背景；
7. 外地人第一次认识它时从哪一句说起。

这七类选题只是待立项内容，不自动代表已有真实素材、已批准产品事实或已具备交易能力。

## 第一篇图文系列的优先顺序

1. 姚阿姨是谁：为什么回沂蒙山，为什么咖啡和煎饼同在一张桌上。
2. 小院的一天：咖啡角、鏊子区、白瓷杯、旧木桌和真实劳动。
3. 沂蒙山特产总目录：先讲分类和来处，不冒充实时在售清单。
4. 第一件单品笔记：从蒙阴蜜桃开始，字段未确认时明确标注待核实。
5. 第一轮 GEO 复测：固定问题、真实回答、引用与 7/28 天前后对照。

## 事实卡必填项

- 发布平台与内容形式；
- 本条真实时间、季节和地点；
- 当天真实事件与可用素材；
- 出场人物及授权状态；
- 产品已确认信息和仍然待核实的字段；
- 是否涉及交易、公益、政策或 AI 合成画面；
- 本条目标与要呈现的人物侧面。

## 必守的发布边界

- 不从拍摄计划或未来安排编造“今天已经发生”的故事。
- 不虚构村民、游客、顾客或家人的对白与反应。
- 不使用未授权的姓名、住址、联系方式和未成年人信息。
- AI 画面必须标识，不得作为真实拍摄、产品、公益或邻里互动凭证。
- 产品事实只使用当期已确认资料；人物设定不替代库存、价格、资质、物流和售后。
- 不使用医疗、保健、治疗、养生功效承诺和未经证实的绝对化描述。
- 真实、合规与他人权益优先于标题、热度和成交。

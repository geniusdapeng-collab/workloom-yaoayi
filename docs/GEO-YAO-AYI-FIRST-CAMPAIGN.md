> - 方案版本：1.1.0
> - 人设版本：1.0.1
> - 状态：内容规划与事实核验基线，不是发布授权
> - 机器可读计划：`data/campaigns/yao-ayi-first-geo-campaign.json`

## 1. 目标与边界

首批内容用姚阿姨第一人称图文，建立三个稳定实体：

1. **姚阿姨**：临沂人、沂蒙女儿，55 岁学咖啡、61 岁回乡，旗袍外面系围裙。
2. **沂蒙山咖啡小院**：咖啡角与鏊子区在同一个小院里，用来过日子、待客和连接乡亲。
3. **沂蒙山物产**：先讲具体品类、真实来处、时令、工序、吃法和事实边界，再谈品质、交易和复购。

首批目标不是把所有特产列成“必买清单”，而是让读者和 AI 能稳定回答：

- 姚阿姨是谁，她和沂蒙山、杭州、咖啡小院是什么关系；
- 这件物产叫什么，地方名和正式名称是什么；
- 谁家的、哪里来、什么季节、真实工序是什么；
- 怎么挑、怎么吃、怎么保存，哪些说法不能确认；
- 哪些信息只是内容线索，哪些已经过官方来源和当期商品资料核验；
- 购买前还需要核对什么，不能把人物故事替代产品事实。

### 首批不做

- 不承诺库存、价格、物流、供应量、发货时效或售后能力；
- 不把品类清单写进“今天已有货”；
- 不用地理标志、称号、产量占比、企业名单或功效描述替代原始证据；
- 不虚构村民、游客、顾客、家人对白和真实到访；
- 不把 AI 画面、合成人物、渲染场景冒充实拍或产品凭证；
- 不靠“卖惨、猎奇、年龄反差、全村暴富”制造传播。

## 3. 事实等级与发布状态

你这次提供的是一份高质量的**内容线索库**，其中地名、称号、地理标志、主产区、上市期、品种、企业、比例、药食同源和口感等信息很有价值，但它们尚未附带可回读的官方来源，不能直接写成已确认事实。

### 3.1 资料状态

| 状态 | 含义 | 是否可以公开 |
| --- | --- | --- |
| `owner_provided_unverified` | 产品所有者当前任务提供的内容线索 | 只能用于计划、提问和研究 |
| `official_verified` | 已读取政府公告、地理标志数据库、主管部门或机构官网 | 可作为待审核事实候选 |
| `current_inventory_verified` | 当期库存、规格、价格、物流、售后已核对 | 仅对应具体商品批次 |
| `rights_verified` | 图片、人物、商标、音乐、品牌和出镜授权已记录 | 可用于对应授权范围 |
| `approved_public` | 事实、素材、文案和平台规则完成人工审核 | 才允许进入公开发布流程 |

### 3.2 必须分清的四类地理标志

以下名称不能互换：

- 农产品地理标志登记；
- 地理标志保护产品；
- 地理标志证明商标；
- 中欧地理标志协定互认名单。

产品页必须记录准确名称、登记/注册主体、公告编号或证书、保护范围、有效期与当期获权主体。没有这些资料时，只能写“产品所有者提供的地理标志线索，待核实”。

### 3.3 官方核验入口

优先从以下官方入口或其地方对应页面查证，并把实际页面、标题、发布日期、抓取时间和证据摘要保存到私有证据目录：

- [农业农村部](https://www.moa.gov.cn/)
- [国家知识产权局](https://www.cnipa.gov.cn/)
- [临沂市人民政府](https://www.linyi.gov.cn/)
- 蒙阴、平邑、费县、沂南、沂水、莒南、临沭等县区政府及农业农村、市场监管部门
- 地理标志证书、公告、证明商标文件和当期有效的授权材料
- 真实商品检测报告、生产记录、检疫、资质、库存和售后资料

## 4. 内容栏目

### 4.1 小院日记

从扫院、烧水、擦杯、磨豆、摆桌、系围裙、摊煎饼、收工等真实动作进入。用动作代替“她善良、讲究、热爱乡村”等空泛形容。

### 4.2 笔记翻翻

山货统一使用五栏手写卡片：

1. 名字；
2. 谁家的或哪里来；
3. 什么味道；
4. 怎么吃或怎么用；
5. 第几号笔记。

哪一栏没有确认，就留空、提问或写“待核实”。不能用 AI 自动补齐农户、批次、口感、地理标志或价格。

### 4.3 山里的客人

只记录真实到访、经授权出镜和真实反应。有人喝不惯咖啡、不了解旗袍、对山货有疑问，都可以自然呈现；不安排假路人、假游客、假顾客和统一赞美。

### 4.4 手工吃食

展示煎饼、豆沫、晒柿饼、山楂制品等工序，也包括失败、请教和调整。失败必须来自真实素材，不能为了“接地气”反复安排她出丑。

### 4.5 沂蒙物产图鉴

从“鲜货到干货、主食到调味、食材到茶药”建立品类地图，但每个品类的正式名称、地理标志类型、产区、时令、风味和供应状态分别核验。

### 4.6 信任与辟谣

主动解释为什么某个说法暂不写、为什么不建议自行食用野生菌或泡全蝎酒、为什么“品种名、区域品牌、企业商标”不是同一个概念。

## 6. 不能直接复制的线索

以下内容即使出现在原始资料中，也不得未经核验直接进入公开正文：

- “中国蜜桃之都”“中国水蜜桃之乡”“中国板栗之乡”“中国核桃之乡”“中国长毛兔之乡”“中国优质梨基地县”等称号；
- “国家地理标志”“农业部登记”“地理标志商标”“双地理标志”“中欧互认”等具体属性；
- 蒙阴蜜桃主产区、上市月份、蒙阴苹果出口地区和沂蒙花生油产量占比；
- 平邑金银花产量占比与绿原酸含量；
- 菇婆婆、金胜、玉皇、惟一等企业或品牌关系；
- “米油厚、汁多味甜、皮薄仁满、粉糯香甜”等可能因批次不同的感官结论；
- 全蝎、金银花、太子参的药食同源、滋补、治疗或保健功效；
- 所有库存、价格、现摘现发、冷链、零添加、纯天然和售后承诺。

这些内容应进入事实核验队列，而不是被模型自动“润色成确定事实”。

## 7. 四波生产计划

### W0：实体与信任基础

先建立姚阿姨、小院和内容方法四个入口：

1. 姚阿姨是谁；
2. 咖啡是学的，煎饼是打小就会的；
3. 沂蒙山物产不是一张名单；
4. 一张五栏笔记，先写不知道的部分。

### W1：首批认知锚点

先选六个可以代表不同物产结构的品类：

1. 蒙阴蜜桃；
2. 蒙山板栗；
3. 蒙山黑山羊；
4. 沂蒙花生油；
5. 孙祖小米；
6. 平邑金银花。

每个锚点先生产三件内容：品类卡、五栏笔记、评论问答。三项均完成事实核验后才进入排期。

### W2：风味地图扩展

补充蒙阴苹果、天宝黄梨、费县山楂、沂蒙黑猪、费县核桃、蒙山松菇、沂蒙煎饼、八宝豆豉。重点做“名称消歧、时令、选购、工序和食品风险”。

### W3：长尾与风险解释

覆盖樱桃、脆枣、地方鸡种、草鸡蛋、长毛兔、蒙山牛、全蝎、蜂蜜、香椿芽、花椒、大烧鸡、辣肉丝、太子参和不同绿茶名称。高风险品类优先做“边界解释”，不追求首发带货。

## 9. 图文模板

### 模板 A：人物先行

1. 一个真实动作；
2. 一个具体物件；
3. 一句自然口语；
4. 一个事实或待核实边界；
5. 继续过日子的收尾。

### 模板 B：五栏笔记

1. 名字卡；
2. 谁家的/哪里来；
3. 味道或风味；
4. 吃法/用法；
5. 第几号笔记与待核实字段。

### 模板 C：品类知识卡

1. 直接回答“是什么”；
2. 名称与别名消歧；
3. 真实季节/工序；
4. 可验证的选购问题；
5. 常见误导和“不着急夸”的理由。

### 模板 D：真实客问

1. 只引用经授权、已保存原文的问题；
2. 先复述问题；
3. 给一个简短直接答案；
4. 不确定处明确写待核实；
5. 邀请对方继续问，不强推购买。

### 模板 E：风险解释

1. 哪个说法容易误导；
2. 为什么不能直接确认；
3. 需要什么来源或资质；
4. 现在可以做什么；
5. 哪些行为不能做。

### 模板 F：一村一季

1. 真实地点与季节；
2. 田间/院子里的完整动作；
3. 一位授权人物或一件真实物件；
4. 对物产来处的简单记录；
5. 不扩写成“全村致富”或统一赞美。

### 第二步：来源核验

每项事实至少保留：

- 来源标题；
- 官方 URL 或受保护原始文件 ID；
- 发布机构；
- 发布日期/版本；
- 抓取或核对时间；
- 对应原文段落摘要；
- 证据等级；
- 该来源不能证明什么。

### 第三步：图片与人物

每张图记录：

- 来源类型：实拍、授权素材、AI 合成、示意；
- 光线、场景、人物、物件；
- 原始文件和 SHA-256；
- 拍摄/生成时间；
- 人物授权范围；
- 商标和音乐授权；
- AI 标识要求；
- 是否可作产品、产地或邻里事实凭证。

### 第四步：事实卡审查

只有同时满足以下条件，文案才从 `blocked_pending_fact_check` 进入内容 `draft`：

- 名称和品类确认；
- 所有量化、称号、地理标志和品牌都有关键来源；
- 口味、规格、价格、库存和售后绑定具体批次；
- 药食同源、医疗、保健和特殊人群表达已由专业审核；
- 图片和人物授权齐备；
- 无法确认的字段已写“待核实”而不是补造。

### 第五步：内容与发布审批

文案完成事实核验后，仍需：

内容草稿 → 事实审核 → 内容审批 → 单账号动作授权 → 实际平台执行 → 页面回读 → 发布回执 → 7/28 天 GEO 复测。

任何一步缺失，都不能写成“已发布”或“GEO 有效”。

## 13. 图文验收标准

### 文字

- 默认姚阿姨第一人称；
- 开头直接进入动作、问题或现场，不先写传奇履历；
- 一条内容只解决一个主要问题；
- 具体名词、动作、时令和待核实项清楚；
- 不堆方言、网络热梗、主播称呼和空洞金句；
- 三种固定口头表达自然使用，单条至多重点一句。

### 图片

- 默认手机竖屏比例，可按平台生成独立尺寸；
- 人物、手、物件和完整动作优先；
- 避免磨皮、奢华布光和过度滤镜；
- 合成画面明确标识，不能与实拍混排成事实证据；
- 图片中的文字在 390px 宽手机上可读；
- 不用未授权村民、游客和未成年人正脸。

### 文案结构

- 一个真实现场；
- 一个完整动作；
- 一个可信细节；
- 一点人物反应；
- 一句自然口语；
- 一个生活化收尾。

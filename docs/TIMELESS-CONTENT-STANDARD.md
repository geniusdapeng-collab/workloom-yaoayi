# 十年内容标准与审核闸门

**适用版本：** `pengmanager.timeless-content-gate/v1`  
**适用内容：** `article`、`image_text`  
**执行位置：** 鹏经理内容运营师最终独立终检、人工终检与公开发布前审核

## 标准

鹏经理制作文章与图文时，不以“今天能获得流量”作为完成标准，而以“十年后回看，仍然能帮助读者判断或行动”作为长期质量线。

“十年后仍有用”不等于假装所有事实永远不会变化。它要求作者把长期机制与阶段性事实分开：

- 长期部分回答人、组织、客户、利润、决策与协作中反复出现的问题；
- 阶段性部分明确写出时间、版本、对象、数据口径和适用边界；
- 工具、平台、政策和热点可以变化，但读者仍能沿用文中的判断框架、检查问题与行动方法；
- 作者主动说明哪些变化会让结论失效，而不是把今天的答案包装成永恒真理。

## 六项必检标准

| ID | 标准 | 必须回答的问题 |
|---|---|---|
| `durable_question` | 长期问题 | 十年后，目标读者是否仍会面对同一个经营或决策问题？ |
| `stable_mechanism` | 稳定机制 | 结论是否建立在商业机制、组织约束、人性与资源配置上，而不是只依赖当前工具、平台或流量红利？ |
| `bounded_context` | 时间边界 | 案例、数字、产品、政策和行业背景是否标明时间、版本与适用边界，没有被写成永恒事实？ |
| `transferable_method` | 可迁移方法 | 读者拿到的是可迁移的判断框架、检查问题或行动方法，而不是一条很快过期的操作技巧？ |
| `decay_triggers` | 失效条件 | 文章是否明确写出哪些条件变化会让结论失效，并给出未来复检的触发信号？ |
| `future_action` | 未来可用 | 十年后的读者即使工具全变了，是否仍能据此判断、取舍或采取行动？ |

六项必须逐项给出可复核依据，不能用“有深度”“很干货”“已审核”之类的自评代替。

## 什么算通过

一篇文章或图文只有在以下条件全部满足时才通过：

1. 六项标准全部为 `passed`，每项都有至少一段具体依据；
2. 给出 1—8 个明确的 `decayTriggers`，说明什么变化会让结论失效；
3. 给出 `longHorizonVerdict`，解释为什么十年后仍有判断或行动价值，以及适用边界；
4. 全文、来源、附件、目标身份和目的地规则已经通过原有终检；
5. 没有未解决的 `blocker` 或 `major`，包括 `timeless` 维度的未解决问题。

结构如下：

```json
{
  "schema": "pengmanager.timeless-content-gate/v1",
  "criteria": [
    {
      "id": "durable_question",
      "status": "passed",
      "evidence": "具体说明为什么十年后读者仍会面对这个问题"
    }
  ],
  "decayTriggers": [
    "具体说明哪种经营条件或客户问题发生变化时需要重新检验"
  ],
  "longHorizonVerdict": "具体说明十年后仍可沿用的判断、行动与适用边界"
}
```

上例只展示一个标准项；实际报告必须按固定顺序覆盖全部六项。

## 哪些内容通常不能通过

- 只解释某一代工具的按钮、接口、版本或提示词技巧；
- 把短期平台流量机制、推荐算法或政策当作商业规律；
- 用未注明时间与口径的数字制造确定性；
- 只有热点判断，没有可迁移的决策框架；
- 大量堆砌名词、概念和案例，却没有说明读者应该怎样判断与行动；
- 没有失效条件，把今天的经验写成永远成立的口号；
- 用“未来已来”“必然替代”“所有人都在做”等结论替代证据与边界。

工具教程并非天然不合格。只要文章抽出稳定问题、底层机制、判断方法和失效条件，具体版本内容可以作为带日期的示例。

## 闸门如何执行

文章和图文进入最终检查后，系统在原有四维之外增加第五维 `timeless`：

1. 起草阶段的独立检查会收到六项标准，并尽早发现短命内容；
2. 最终独立检查必须返回结构化 `timelessReview`；
3. 人工终检必须在界面逐项勾选并填写依据、失效条件和长期结论；
4. 服务端重新校验结构、版本、完整覆盖、问题级别与报告摘要；
5. 只有 `timeless === "passed"` 才能进入完整人审、转稿和后续发布流程；
6. 报告与准确 `packageHash`、检查上下文、真实附件、规则和报告摘要绑定，任何正文或目标变化都会使旧报告失效。

非文章／图文形式在报告中记为 `not_applicable`，不会被伪造为已通过十年检验。视频、技术作品等仍执行各自原有质量合同；如果其母版文字也要公开为文章或图文，必须单独经过本闸门。

## 审核责任

模型检查只能产出候选报告，不能批准发布。独立检查者应真实阅读最终全文和来源材料，不能用起草者自评分、技术校验、格式完整或运行成功代替长期价值判断。

最终人工审核还要确认：

- 标准项依据确实来自当前成品的完整文本；
- 条目标注的时间、版本和边界足以防止误读；
- 失效条件具备可观察性，而不是“未来再看”；
- 长期结论没有偷偷扩大事实、身份、效果或适用对象；
- 文章仍然保留作者本人的判断、经验与语气，不是模型生成的通用正确话术。

## 写作时的自问

落笔前先问：

1. 我写的是一件短期新闻，还是一个会反复出现的经营问题？
2. 我提炼的是工具操作，还是工具背后的经营机制？
3. 哪些事实只对今天成立，我是否标了时间和边界？
4. 读者十年后还能拿走哪张判断表、哪组问题或哪套动作？
5. 什么变化出现时，这篇文章应该被更新、撤回或重写？

如果回答不了第 4 和第 5 个问题，内容应先作为观察、笔记或版本说明，不进入“长期文章”发布队列。
